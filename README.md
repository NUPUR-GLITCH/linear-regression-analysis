# 📌 Project Overview

Machine Learning enables computers to learn patterns from data and make intelligent predictions. This project provides a hands-on implementation of **Simple Linear Regression**, one of the most fundamental supervised learning algorithms used in predictive analytics.

Using a real-world **Student Scores** dataset, the model learns the relationship between study hours and exam performance, demonstrating how machine learning can identify trends and generate accurate predictions.

The project follows a complete ML workflow—from data exploration and preprocessing to model training, evaluation, and visualization—making it an excellent foundation for beginners entering the field of Artificial Intelligence and Data Science.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/Linear-Regression-Analysis.git
```

## Navigate to the Project

```bash
cd Linear-Regression-Analysis
```

## Install Dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn notebook
```

## Launch Jupyter Notebook

```bash
jupyter notebook
```

Open **linear regression.ipynb** and execute the cells sequentially.
